A test demo for static extraction of krkrz xp3 package with Cxdec(hxv4) encryption  
usage((make sure Soft-Denchi drm removed)):
```bash
cxdecgo.exe -d <path to gameexe>
cxdecgo.exe -r <path to xp3 pack>
```
-d: dump bootstrap first
-r: unpack xp3 pack then

# reference
analysis from https://github.com/hktkqj/cxdec-hxv4-static-analysis
